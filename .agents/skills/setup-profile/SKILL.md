---
name: setup-profile
description: Create or update the user's profile file (profile/profile.md) through an interview. Use when profile/profile.md is missing, or the user wants to add or change their name, home address, projects and project codes, or company rules.
---

Build `profile/profile.md` from `profile/profile.template.md` by interviewing the user. Ask one question at a time.

## If `profile/profile.md` does not exist

1. Copy `profile/profile.template.md` to `profile/profile.md`.
2. Ask for, in order:
   - Full name
   - Home address
   - Projects and their project codes (repeat until the user says there are no more)
   - Company rules that matter for expenses (free-form; may be left empty)
3. Write the answers into the matching sections and remove the template instruction line at the top.

## If `profile/profile.md` already exists

1. Read it and summarize what is filled in and what is missing.
2. Ask only about missing items or what the user wants to change, for example adding a project.
3. Show the intended edits and get confirmation before changing anything. Never overwrite existing content without confirmation.
